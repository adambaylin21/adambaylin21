## 👋 About

I'm **Phạm Văn Hải** — an automation-focused developer at **Theory Of Future**. My work sits at the intersection of *repetitive work* and *"there has to be a better way"*: I build tools that scrape, transform, convert, and export data so people can spend their time on decisions instead of manual steps.

Most of my repositories are born from a real bottleneck — a form that takes an hour to fill, a video batch that needs processing, an API that needs a bridge. I ship the fix, then publish it in case it helps someone else.
